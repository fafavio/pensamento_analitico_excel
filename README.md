# 📊 Projeto de Análise de Dados com Excel

## 🎯 Objetivo

Este projeto foi desenvolvido com foco em praticar **capacidade analítica**, estruturação de contexto de negócio e criação de indicadores (KPIs), utilizando apenas o Excel.

O principal objetivo não foi apenas aplicar fórmulas, mas sim treinar o pensamento analítico: entender o problema antes de analisar os dados.

---

## 📌 Contexto do Projeto

Foi realizado um levantamento de necessidades de negócio para estruturar uma análise sobre:

- Tempo de entrega
- Estado de entrega
- Tipo de pagamento
- Custo do frete
- Volume de pedidos

A base de dados e a ideia inicial foram inspiradas em um vídeo do YouTube:

https://www.youtube.com/watch?v=wdzffBz9XtA

No entanto, **não copiei o projeto**.  
Criei meu próprio levantamento de necessidades, defini minhas próprias perguntas de negócio e estruturei a análise de forma independente.

---

## ❓ Perguntas de Negócio

- Qual estado entregou mais rápido?
- Qual tipo de pagamento obteve melhor tempo de entrega?
- O custo do frete influencia na velocidade de entrega?

---

## 📊 Indicadores (KPIs) Utilizados

- Tempo médio de entrega
- Tempo médio de entrega por estado
- Tempo médio de entrega por tipo de pagamento
- Análise entre custo do frete e tempo de entrega
- Custo total
- Quantidade total de pedidos

Todos os indicadores foram calculados utilizando fórmulas do Excel.

---

## 🛠 Ferramentas Utilizadas

- Microsoft Excel
- Fórmulas (MÉDIA, MÉDIASE, SOMA, CONT.SE)
- Tratamento e limpeza de dados
- Gráficos para visualização dos resultados

*(Não foi utilizada Tabela Dinâmica neste projeto.)*

---

## 📈 Resultados Obtidos

A análise permitiu identificar padrões no tempo de entrega entre estados e tipos de pagamento, além de observar a relação entre o custo do frete e a velocidade de entrega.

O projeto reforçou a importância de definir contexto e KPIs antes de iniciar a análise.

---

## 🚀 Aprendizado

Mais do que aprender Excel, este projeto foi uma prática de:

- Pensamento analítico
- Estruturação de problemas
- Definição de indicadores
- Transformação de dados em insights
