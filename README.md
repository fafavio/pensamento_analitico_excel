📊 Análise de Dados com Excel – Foco em Capacidade Analítica
🚀 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de praticar capacidade analítica, estruturação de contexto de negócio e criação de KPIs utilizando apenas o Excel.

Mais do que aplicar fórmulas, o foco foi:

Definir um problema de negócio
Criar perguntas estratégicas
Estruturar indicadores
Transformar dados em insights
📌 Contexto

Foi realizado um levantamento de necessidades de negócio para estruturar uma análise sobre:

Tempo de entrega
Estado de entrega
Tipo de pagamento
Custo do frete
Volume de pedidos

A base de dados e a ideia inicial foram inspiradas em um vídeo do YouTube:

🔗 https://www.youtube.com/watch?v=wdzffBz9XtA

No entanto, o projeto não foi copiado.
Foi desenvolvido um levantamento próprio de negócio para dar sentido real à análise.

❓ Perguntas de Negócio
Qual estado entregou mais rápido?
Qual tipo de pagamento apresentou melhor tempo de entrega?
O custo do frete influencia na velocidade da entrega?
📊 KPIs Desenvolvidos
Tempo médio de entrega
Tempo médio por estado
Tempo médio por tipo de pagamento
Análise de frete vs tempo de entrega
Custo total
Quantidade total de pedidos
